# Calculator UI Design

Author: Trevione Moses

## Overview

This project demonstrates the design of a calculator application using Swift and StackView concepts.

The calculator contains:

- Display area
- Number buttons
- Operation buttons
- Equal button

The layout is designed to support:

- iPhone Portrait
- iPhone Landscape
- iPad Portrait
- iPad Landscape

## Design Requirements

- Uses StackView layout structure
- Responsive design
- Calculator interface only
- No calculation functionality required

## Technologies

- Swift
- SwiftUI
- VStack
- HStack

## Note

This project is intended to demonstrate UI design only.
